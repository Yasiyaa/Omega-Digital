## ?? Overview

**Omega Innovation** is a high-performance digital agency web application engineered with React, Vite, Framer Motion, and Lenis smooth scrolling.

### Key Capabilities
- **Floating Frosted Glass Navigation**: Dynamic scroll-state responsive pill with seamless mobile drawer and touch lock.
- **Fullscreen Video Hero Banner**: Cinematic looping banner with frosted trust ticker.
- **Studio Manifesto**: Editorial dual-column narrative highlighting operational cohesion and metrics.
- **Three Flagship Pillars**:
  1. **Business Cards & Full Company Branding** (Logo Design, Stationery Suite, Staff Identity, Digital Brand Kits, Brand Books)
  2. **Corporate Websites** (Brand-Aligned UI/UX, 1-Year Free Hosting & Domain, Business Email, SEO Architecture)
  3. **Web App Solutions for Business** (Company Backend Systems, Production Platforms, Supply Chain & Logistics, Workflows)
- **Interactive Methodology**: 4-step structured delivery process with background immersion.
- **Selected Deployments**: Featured case study of **Monarch Services** ([Live Site](https://monarch-vert-six.vercel.app/)).
- **Consultation Portal**: Interactive project scoping and requirement submission form.
- **Zero Horizontal Play**: Bulletproof mobile responsiveness with strict viewport containment.

## ?? Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation
`ash
# Clone the repository
git clone https://github.com/Yasiyaa/Omega-Digital.git
cd Omega-Digital

# Install dependencies
npm install

# Start development server
npm run dev
`

### Production Build
`ash
# Compile optimized production bundle
npm run build

# Preview production build locally
npm run preview
`
